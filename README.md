# Review de Base de Datos MySQL

## Descripción
Repositorio de práctica y consolidación de conocimientos en **MySQL**. El proyecto abarca desde el diseño y creación de esquemas relacionales hasta la implementación de lógica avanzada dentro de la base de datos, incluyendo:

* **Lógica programada:** Procedimientos almacenados, funciones, *triggers* (disparadores), bucles y eventos programados.
* **Manejo de excepciones:** Control y gestión de errores para garantizar la integridad de los datos y la robustez en la ejecución.
* **Consultas avanzadas:** Optimización de consultas complejas, uniones (*joins*), subconsultas y manipulación de datos.

Asimismo, el desarrollo fue estructurado mediante un flujo de trabajo basado en ramas, asegurando un control de versiones limpio y ordenado.
